# BOSS 牛人推荐数据源与粗筛采集交接

日期：2026-10-13（Asia/Shanghai）  
范围：本会话已探索的牛人推荐、沟通列表与在线简历读取路径。本文记录可实现程度，不代表牛人推荐页全部信息、所有候选人或长期运行已验收。

## 核心结论

- **联系前粗筛**：可以从已登录的牛人推荐页面读取推荐卡片及其页面/接口中已提供的候选人资料。它适合做初筛输入，但不能直接等同于候选人的完整在线简历。
- **联系后深筛**：对已有沟通关系的候选人，本会话曾通过 BOSS 在线简历数据保存一份较详细的结构化简历；这是单个真实样例，不证明推荐列表中的所有人都能在联系前取得同等详情。
- **截图路线**：Chrome 扩展曾实现局部截图并围绕长页滚动截图多次迭代。它不应作为目前获取完整粗筛文本的首选，也没有在本会话中形成“所有推荐简历均可稳定完整长图采集”的验收证据。

## 推荐的粗筛输入边界

1. 联系前使用**推荐卡片 + 该页面实际可读的展开资料/运行时字段**，保留候选人来源、采集时间、字段原文和缺失字段标记。
2. 将截图/OCR 作为页面文本缺失时的补充证据，记录截图覆盖的区域；不要把未截到的段落推定为空。
3. 建立沟通后，再把在线简历、聊天记录或附件加入深筛。粗筛与深筛的字段来源分开存储，避免把联系后获得的信息回填成联系前已知。
4. 对每一字段标明“列表可见 / 展开页可见 / 页面数据 / OCR / 沟通后简历”，并保留原始文件路径供复核。
