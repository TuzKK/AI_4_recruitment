# SyntheticResumeData

SynthResume 是一个包含 2,994 份合成简历的语料库，通过半自动化的 LLM 驱动生成流程构建。具体构建流程如下：

- **模板多样性**：收集并整理了涵盖校招、社招等多场景的多样化简历模板，覆盖单栏、双栏、多栏、图文混排等复杂版式；
- **内容生成**：利用大语言模型（LLM）在模板中填充随机但语义合理、格式合规的虚构内容；
- **结构化标注**：每份生成的简历首先通过 Qwen-Max 进行版面解析与字段预标注，随后由人工校验与修正，确保标注质量与一致性。

该数据集有效缓解了真实简历标注成本高、隐私敏感等问题，同时显著提升了模型对复杂版式的泛化能力。

## 目录结构

resume_list_pdf中为简历合成的pdf

result_gt中为对应简历标注的ground_truth

该数据可用于下游任务如简历解析，版面分析等任务的训练和微调。
